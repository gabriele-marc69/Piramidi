# Section 5.4–5.19: Catalog of Newly Discovered Structures & Metric Determination

## Core Idea
The paper's headline claim: 20 distinct internal structures (corridors, rooms, and two "complex structures"), most previously unreported, are tagged, cross-referenced to specific tomographic figures, and given approximate physical measurements.

## Frameworks Introduced
- **Unique-tag cataloging scheme**: every discovered feature gets one persistent number (1–20) used consistently across the 3D model, tomogram figures, and measurement tables — enabling traceability from "a bump in a tomogram" to "a named, numbered, measured structure."
  - When to use: any exploratory-imaging project producing many candidate features — assign IDs immediately so later cross-referencing/discussion doesn't rely on ad hoc descriptions.
- **Metric determination via internal calibration**: structure dimensions are estimated using image-measurement software calibrated against the pyramid's known base length as an internal ruler, rather than absolute geolocation.

## Key Concepts
- **Complex structure**: the paper's category for multi-part features that aren't simple single corridors/rooms (structures #9 and #10 — the northern underground complex and the "Zed complex structure").
- **False alarm flag**: the authors explicitly identify one tomographic feature (a bright target near structure #19, "Big Void") as a false alarm caused by the pyramid's southwest ascending-angle geometry, not a real structure — an example of the paper self-flagging a known artifact.

## Worked Example
Structure #17 ("little void," behind the original entrance) plus #18 ("front corridor") are presented together: the void is not directly connected to the Grand Gallery despite a horizontal conduit appearing to run toward it — an example of the paper distinguishing "visually near" from "structurally connected" based on the tomographic signature rather than assumption.

## Anti-patterns
- **Treating every bright tomogram feature as a real structure**: the paper's own flagged false alarm (near tag 19) shows why each tomographic feature needs independent geometric plausibility checking against known artifact sources (e.g., pyramid corner/edge angles) before being cataloged.

## Key Takeaways
1. 20 tagged structures were cataloged; most (corridors 1–9, rooms 11–20) are presented as newly discovered, while a few connect to or reinterpret known features.
2. Structure identification is explicitly said to use **no simulated data or predictive models** — the authors state each tag is read directly from measured tomograms.
3. Reported dimensions include material thickness, not just void space — the authors note ongoing work to separate solid from hollow signal.
4. At least one tomographic feature was proactively identified and excluded as a geometric false alarm — a data-quality practice worth noting when evaluating the catalog's reliability.
